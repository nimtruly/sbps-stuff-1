# Cinematic reel ideas: Robotics and NDA

Ad-film-grade concepts for the SBPS in-house crew. This folder is separate from the phone-shot plan in [`../reels-robotics-nda.md`](../reels-robotics-nda.md), which stays as it is.

- One file per idea, five per topic.
- Every idea is built on a technique from a reel that measurably travelled. See [REFERENCES.md](REFERENCES.md) for the links, numbers and frame notes.
- Hinglish throughout. Every film opens on a child.
- Anything marked **TO CONFIRM** needs the school's sign-off before the shoot.

## Crew notes that apply to all ten
- **Deliver vertical first.** Compose for 9:16 with the safe zone (nothing important in the top 230px, the bottom 480px or the right 230px of 1080x1920). If you also need 16:9 for YouTube, shoot open-gate and frame for both.
- **First frame moves.** No logo sting, no school name until the end.
- **Burn in Hinglish subtitles** for every spoken line.
- **Music:** licensed or Instagram library only, or the ad boost gets blocked.
- **Consent:** written parental consent for every child on camera, including voices (R3).
- **No rendered kids.** Two high-view school reels in the research were AI-generated. Every SBPS film must be real footage of real students.
