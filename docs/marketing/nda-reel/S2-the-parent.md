## Shoot notes

- **Parent:** V1–V4: a real parent or staff member, in everyday clothes. V5: a real NDA-batch parent with written consent; don't script their answers.
- **Posters and flyers:** V1 uses PO1–PO2 (made-up academy). Before printing, check the made-up name doesn't belong to a real academy. V2+ use generic PO3–PO5 (no name, no logo, no phone).
- **Phone screen (V4):** build the search screen as a graphic (PO6), with made-up listings only. Never film a real search page.
- **Interview line:** let the student give a real answer. Only fall back to the scripted line if needed.
- **Consent:** written parental consent for every student on camera.
- **Uniform:** PT kit and BDA bibs only. No army uniform or insignia on students.
- **Captions:** burn in Hinglish subtitles.
- **Format:** 9:16, 1080×1920. Keep text out of the bottom 20% and right edge.
